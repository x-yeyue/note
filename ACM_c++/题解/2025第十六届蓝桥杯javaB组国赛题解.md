# [P12885 [蓝桥杯 2025 国 Java B] 农场监控](https://www.luogu.com.cn/problem/P12885)

> **题目描述:**
> 
> 一位农民正在规划他的高科技农场，他希望利用无人机和摄像头对农作物进行实时监控。为了实现这一目标，他将农场划分为一个 $2025 \times 2025$ 的网格，其中每个网格单元代表一小块农田。整个网格中共有 $2026 \times 2026$ 个顶点（即网格线相交形成的点），这些顶点可以作为监控设备的安装位置。
> 
> 为了提高监控效率，农民决定选择一个矩形区域进行重点监测。具体来说，他会选择网格中 4 个不同的顶点作为矩形的四个顶点，并且保证矩形的边必须平行于网格的水平或垂直方向。
> 
> 现在，请你帮助这位农民计算，总共有多少种方法，可以选择 4 个点，构成满足上述条件的矩形。两种选法被视为不同的方法当且仅当最后形成的矩形区域不同。
> 
> **输入格式:**
> 
> 无
> 
> 输出格式
> 
> 这是一道结果填空的题，你只需要算出结果后提交即可。本题的结果为一个整数，在提交答案时只填写这个整数，填写多余的内容将无法得分。

## 题目大意

问在一个 $2026 \times 2026$ 的点阵中，选择 $4$ 个不同点组成一个矩形的方案有多少种。

## 题解

换一种方式思考，一个矩形是有由两组相互平行线组成的。

于是，就可以从挑选点转换为挑选线。

对于 $x$ 轴方向上挑选的可能性为 $C_{2026}^{2}$ 种可能，对于 $y$ 轴方向也是相同的 $C_{2026}^{2}$ 种可能。

所以最终答案就为 $\left(C_{2026}^{2}\right)^{2} = 4207934255625$。

**代码:**

```c++
void solve(void){
    cout << "4207934255625" << endl;
}
```

**时间复杂度:** $O(1)$

# [P12886 [蓝桥杯 2025 国 Java B] 分配房子](https://www.luogu.com.cn/problem/P12886)

> **题目描述:**
> 
> 蓝桥小镇有 $20255202$ 栋楼房排成一列，每栋楼有两套房子：一套在一楼，一套在二楼。镇长决定将这些房子分配给本地居民或外来游客居住，并设定了如下规则：
> 
> - 每一栋楼里，必须有一套是本地居民住，另一套是外来游客住。
> - 从本地居民住户中，分别往左、右看同一楼层的邻居。如果某个邻居也住着本地居民，就记录一次（如果某个本地居民的同一楼层的左、右邻居都是本地居民，记录两次）。最后把所有这样的记录加起来，总数是 $5202$。
> 
> 现在，请你计算出满足这两个规则的房子分配方案总数。由于答案可能很大，你只需给出其对 $10^9 + 7$ 取余后的结果即可。
> 
> **输入格式:**
> 
> 无
> 
> **输出格式**
> 
> 这是一道结果填空的题，你只需要算出结果后提交即可。本题的结果为一个整数，在提交答案时只填写这个整数，填写多余的内容将无法得分。

## 题目大意

有 $20255202$ 栋楼排成一列，每栋楼有上下两层。每栋楼必须恰好安排一户本地居民和一名游客（即一层住本地，另一层住游客）。对于同一楼层，若相邻栋楼的该层同为本地居民，则记录 1 次（左右单独计算）。已知所有楼层中这样的记录的总和为 $5202$。求满足条件的分配方案总数（答案对 $10^9+7$ 取模）。

## 题解

可以发现，对于住同一层的两个相邻的本地居民，相互都会贡献一次记录，那么这一组本地居民就会贡献 $2$ 个记录。

已知所有楼层中这样的记录共为 $5202$ 个，那么也就代表了共有 $2601$ 组相邻且在同一楼层的本地游客。

问题就可以转换成，在 $20255202$ 栋楼中挑选 $2601$ 组相邻楼宇的方案数，同时由于其中每一组都可以选择上下两层，所以最终的答案还要乘 $2$。

故答案为 $C_{20255201}^{2601} \times 2 ~\%~ (1e9 + 7) = 728601046$ 。

**代码:**

```c++
const int MOD = 1e9 + 7;

ll fmod(ll x, ll n){
    ll ans = 1;
    while(n){
        if(n & 1){
            ans = ans * x % MOD;
        }
        n >>= 1;
        x = x * x % MOD;
    }
    return ans;
}

void solve(void){
    ll ans = 1;
    ll flag = 1;
    for(int i = 20255201, cnt = 2601; cnt; i --, cnt --){
        ans = ans * i % MOD;
        flag = flag * cnt % MOD;
    }
    ans = ans * fmod(flag, MOD - 2) % MOD;
    cout << ans * 2 % MOD << endl;
}
```

**时间复杂度:** $O(1)$

# [P12887 [蓝桥杯 2025 国 Java B] 答题数量](https://www.luogu.com.cn/problem/P12887)

> **题目描述:**
> 
> 小蓝从一间空荡的房间中醒来，眼前放着一张木桌，桌上摆放着两份密封的答案纸，一份属于他，另一份属于他的朋友。每张纸上都写着一个长度为 $N$ 的字符串，仅包含字符 $\tt T$ 和 $\tt F$ ——这是他们昨晚参加一场判断题考试后的答题记录。
> 
> 考试共有 $N$ 道题目，每题的答案只有两种可能：
> - $\tt T$ 表示 $\text{True}$（正确）
> - $\tt F$ 表示 $\text{False}$（错误）
> 
> 两人在相互隔离、无法交流的情况下各自完成了作答，并提交了自己的答案。
> 
> 今早，小蓝收到了一条神秘信息：
> > “你的朋友恰好答对了 $M$ 道题。”
> 
> 标准答案尚未公布，小蓝无法直接判断自己答对了多少题。然而，基于已知信息，小蓝希望评估出，在所有可能的标准答案中，他自己最多能答对多少题。现在，请你计算小蓝至多能答对的题目数量。
> 
> **输入格式:**
> 
> 第一行包含两个整数 $N$ 和 $M$，分别表示题目数量和朋友答对的题目数量。
> 
> 第二行包含一个长度为 $N$、仅由字符 $\text{T}$ 和 $\text{F}$ 组成的字符串 $S$，表示小蓝的答案。
> 
> 第三行包含一个长度为 $N$、仅由字符 $\text{T}$ 和 $\text{F}$ 组成的字符串 $T$，表示朋友的答案。
> 
> **输出格式:**
> 
> 输出一个整数，表示在所有可能的标准答案中，小蓝最多能答对的题目数量。
> 
> **样例:**
> 
> ```text
> 输入:
> 4 2
> TTFF
> FTTF
> 
> 输出:
> 4
> ```
> 
> **数据规模:**
> 
> 对于 $100\%$ 的评测用例，$2 \leq M \leq N \leq 10^5$。

## 题目大意

有 $N$ 道判断题，已知小蓝的答案字符串 $S$ 和朋友的答案字符串 $T$，且朋友恰好答对了 $M$ 道题。在所有可能的标准答案中，求小蓝最多能答对的题目数量。

## 题解

假设标准答案为 $R$ (长度为 $N$ 的 $T/F$ 串)。

首先，对比下 $S$ 和 $T$ 字符串。

- $S[i] = T[i]$
  该选项小蓝和朋友相同，如果朋友是正确的，则小蓝也正确。
- $S[i] \not = T[i]$ 
  该选项小蓝和朋友不同，如果朋友是正确的，则小蓝是错误的。

设 $S$ 和 $T$ 字符串中相同的有 $A$ 个，不同的有 $B$ 个。

假设在相同的部分中，朋友正确了 $x$ 个，在不同的部分中，朋友正确了 $y = M - x$ 个。

$$
\begin{split}
	\text{小蓝正确的个数} 
	&= \text{相同部分小蓝正确的个数} + \text{不同部分小蓝正确的个数} \\
	&= \text{相同部分朋友正确的个数} + \text{不同部分朋友错误的个数} \\
	&= x + (B - y), \\
	&= x + B - (M - x) \\
	&= 2x + B - M
\end{split}
$$

可以得到，小蓝正确的个数和 $x$ 成正比，所以需要尽可能的让 $x$ 更大。

已知，$0 \le x \le A$ 和 $y = M - x \ge 0$ 即 $x \le M$。

所以, $x$ 最大为 $min(A, M)$。

综上，答案为 $2 \times min(A, M) + B - M$。

**代码:**

```c++
void solve(void){
    int n, m; cin >> n >> m;
    string s, t;
    cin >> s >> t;
    int a = 0;
    int b = 0;
    for(int i = 0; i < n; i ++){
        if(s[i] == t[i]) a ++;
    }
    b = n - a;
    cout << 2 * min(a, m) + b - m << endl;
}
```

**时间复杂度:** $O(n)$

# [P12888 [蓝桥杯 2025 国 Java B] 钟楼管理员](https://www.luogu.com.cn/problem/P12888?contestId=330324)

> **题目描述:**
> 
> 小蓝是小镇钟楼的管理员，负责维护一座古老的时钟。这座时钟的表盘上刻有从 $1$ 到 $N$ 的连续整数，初始时指针指向 $1$。平时，小蓝通过顺时针或逆时针拨动指针调整时间：顺时针拨动一次，指针从当前数字 $x$ 移至 $x+1$（若 $x=N$，则移至 $1$）；逆时针拨动一次，指针从 $x$ 移至 $x-1$（若 $x=1$，则移至 $N$）。
> 
> 然而，一场突如其来的暴风雨损坏了钟楼。表盘因风沙侵蚀变得模糊不清，小蓝无法看清指针的当前位置；机械装置也因故障失灵，导致他拨动指针时方向随机——可能是顺时针或逆时针，且拨动前无法预测方向。
> 
> 小蓝记得暴风雨后他总共拨动了 $K$ 次指针。为了确定指针的最终位置，他希望计算出经过这 $K$ 次随机拨动后，指针最终可能指向的数字有多少个。
> 
> 现在，请你帮助小蓝解决这个问题。
> 
> **输入格式:**
> 
> 输入的第一行包含一个整数 $T$，表示测试用例的数量。
> 
> 接下来 $T$ 行，每行包含两个整数 $N$ 和 $K$，分别表示表盘上的数字个数和小蓝拨动指针的次数。
> 
> **输出格式:**
> 
> 输出共 $T$ 行，每行包含一个整数，表示经过 $K$ 次随机拨动后，指针最终可能指向的不同数字的个数。
> 
> **样例:**
> 
> ```text
> 输入:
> 2
> 4 1
> 5 2
> 
> 输出:
> 2
> 3
> ```
> 
> **样例说明:**
> 
> 对于第一个样例 $N=4, K=1$，表盘有数字 $1, 2, 3, 4$，初始指针指向 $1$。拨动 $1$ 次后，可能顺时针移至 $2$，或逆时针移至 $4$，因此指针最终可能指向的数字有 $2$ 个。
> 
> 对于第二个样例 $N=5, K=2$，表盘有数字 $1, 2, 3, 4, 5$，初始指针指向 $1$。拨动 $2$ 次后，可能的结果为：顺时针两次至 $3$、顺时针再逆时针或逆时针再顺时针至 $1$、逆时针两次至 $4$，因此指针最终可能指向的数字有 $3$ 个。
> 
> **数据规模:**
> 
> 对于 $20\%$ 的评测用例，$1 \leq T \leq 10^2$，$2 \leq N \leq 20$，$1 \leq K \leq 20$。
> 
> 对于 $100\%$ 的评测用例，$1 \leq T \leq 10^5$，$2 \leq N \leq 10^9$，$1 \leq K \leq 10^9$。

## 题目大意

有一个标有 $1$ 到 $N$ 的环形表盘，初始指针指向 $1$。每次操作随机地顺时针或逆时针移动一格。经过 $K$ 次操作后，指针可能到达的位置有哪些？求不同位置的数量。

## 题解

由于题目中为一个环，故将题目中的 $[1, N]$ 区间转换为 $[0, N - 1]$ 区间，方便取余操作(对答案没有影响)。

经过打表可以发现一些规律:

```text
----- N = 7 -----
K = 1  ans = 2
K = 2  ans = 3
K = 3  ans = 4

----- N = 8 -----
K = 1  ans = 2
K = 2  ans = 3
K = 3  ans = 4
```

在指针没有重复经过同一个位置的情况下，

$$\text{不同位置的数量} = K + 1$$

参考下图:

![](https://img2024.cnblogs.com/blog/2918048/202606/2918048-20260607142803454-28174542.png)

从上图中可以看出，在 $N$ 足够大的时候，$\text{不同位置的数量} = K + 1$ 这个公式是一直满足的，那么问题来了，什么时候不满足这个公式呢？

就是当有某个位置的数值被指向多次的时候。这时候就会出现重复，具体的例子可以自行举例。

那么对于已知的 $N$，不考虑 $K$ 的取值，最多能指向多少个不同的数呢？

这里要用到 [环上步长同余定理](https://www.cnblogs.com/hejie001/p/20034691 "环上步长同余定理") 不了解的可以看下，这篇文章我感觉写的蛮好的。

假设在 $K$ 次移动中，顺时针($+1$)移动了 $x$ 次，逆时针($-1$)移动了 $K - x$ 次，那么偏移量就为 $x - (K - x) = 2x - K$。

也就说明在总移动次数 $K$ 固定的情况下，每多顺时针移动一次，最终的偏移量就 $+2$。也就代表了其步长为 $2$。

带入 **环上步长同余定理** 中的求循环节长度公式得到:

$$
\text{循环节长度} = \frac{n}{\gcd(n, k)} = \frac{N}{\gcd(N, 2)} 
$$

这也就代表了，在不考虑 $K$ 的取值的情况下，最多能指向 $\frac{N}{\gcd(N, 2)}$ 个不同的数据。

那么最终的答案就为:

$$
\min(K + 1, \frac{N}{\gcd(N, 2)})
$$

**代码:**

```c++
void solve(void){
    int n, k; cin >> n >> k;
    cout << min(k + 1, n / __gcd(n, 2)) << endl;
}
```

**时间复杂度:** $O(1)$

# [P12889 [蓝桥杯 2025 国 Java B] 情绪链路](https://www.luogu.com.cn/problem/P12889)

> **题目描述:**
> 
> 在数字社交媒体的浩瀚世界中，运营者小蓝负责维护一条情绪链路。这条链路由 $n$ 个用户节点依次排列而成，每个节点上记录着一个情绪值。具体地，第 $i$ 个节点的情绪值为 $a_i$，其中 $a_i$ 是一个整数，可能为正，也可能为负。
> 
> 为了改善整体情绪氛围，小蓝购买了一种名为“情绪放大器”的工具。该工具允许他选择一段**至少包含一个用户节点的连续区间**，并将这个区间内所有用户节点的情绪值都乘以一个整数 $k$。只是，工具启动成本高昂，小蓝只能使用它一次。
> 
> 现在，请你帮助小蓝计算，在经过这样一次操作后（一定要操作），所有用户节点的情绪值之和最大会是多少。
> 
> **输入格式:**
> 
> 第一行包含两个整数 $n$ 和 $k$，分别表示情绪链路的长度和放大器的倍数。
> 
> 第二行包含 $n$ 个整数 $a_1, a_2, \ldots, a_n$，表示每个用户节点的情绪值。
> 
> **输出格式:**
> 
> 输出一行，包含一个整数，表示经过一次操作后，所有用户节点情绪值之和的最大可能值。
> 
> **样例:**
> 
> ```text
> 输入:
> 5 2
> -1 2 -3 4 -5
> 
> 输出:
> 1
> ```
> 
> **样例说明:**
> 
> 最优的做法是选择区间 $[4]$ 并使用工具。使用后这 $n$ 个用户节点的情绪值依次为 $[-1, 2, -3, 8, -5]$，总和为 $1$。
> 
> **数据规模:**
> 
> 对于 $30\%$ 的评测用例，$2 \leq n \leq 10^3$，$1 \leq k \leq 10^3$，$-10^3 \leq a_i \leq 10^3$。
> 
> 对于 $100\%$ 的评测用例，$2 \leq n \leq 10^5$，$1 \leq k \leq 10^5$，$-10^5 \leq a_i \leq 10^5$。

## 题目大意

给定长度为 $n$ 的整数序列 $a_1, a_2, \dots, a_n$ 和一个正整数 $k$。允许选择一段非空的连续子区间，将该区间内的每个数乘以 $k$（必须操作一次）。求操作后整个序列的和的最大值。

## 题解

为了让最终的累加和最大，所选的区间的累加和显然越大越好，其累加和越大，乘 $k$ 以后的累加和也就更大。

那么问题就转换为了寻找这个序列中累加和最大的子数组。

显然可以使用 $DP$ 来解决，在递推的过程中，同时维护累加和最大的区间信息便可。

这是一个非常经典的 $DP$，不了解的可以先学下 **最大连续子数组和**。

**代码:**

```c++
void solve(void){
    int n, k; cin >> n >> k;
    vector<ll> arr(n);
    for(int i = 0; i < n; i ++){
        cin >> arr[i];
    }
    int anslf = -1, ansrt = -1;
    int lf = 0, rt = -1;
    ll mx = -INF;
    ll sum = 0;
    for(int i = 0; i < n; i ++){
        if(arr[i] + sum > arr[i]){
            sum += arr[i];
            rt = i;
        }else{
            lf = i, rt = i;
            sum = arr[i];
        }
        if(sum > mx){
            mx = sum;
            anslf = lf;
            ansrt = rt;
        }
    }
    ll ans = 0;
    for(int i = 0; i < n; i ++){
        if(anslf <= i && i <= ansrt){
            ans += arr[i] * k;
        }else{
            ans += arr[i];
        }
    }
    cout << ans << endl;
}
```

**时间复杂度:** $O(n)$

# [P12890 [蓝桥杯 2025 国 Java B] 道具摆放](https://www.luogu.com.cn/problem/P12890)

> **题目描述:**
> 
> 小蓝是社区剧团的道具员，他负责管理一排编号为 $1$ 到 $N$ 的道具箱。平常，这些道具箱会按编号升序排列在舞台上。
> 
> 今天晚上有一场重要的演出，演出开始前，导演小李递给小蓝一份清单，上面写着他想要的道具箱排列顺序：$P_1, P_2, \ldots, P_N$。导演希望小蓝在演出过程中将这排箱子调整成这个顺序。由于舞台空间狭小，每次调整只能交换相邻两个箱子的位置。且每完成一次交换，舞台灯光就会闪烁一次作为提示。
> 
> 灯光系统有个特别的节奏设定：每进行 $M$ 次闪烁，灯光就会切换一种模式。为了配合这种节奏，导演强调：必须在某次灯光切换模式的那一瞬间完成所有调整工作。这意味着，小蓝完成调整所需的交换次数必须是 $M$ 的整数倍。
> 
> 现在，请你帮小蓝计算一下，他最少需要多少次交换操作才能按照导演的要求完成调整。如果无论如何都无法满足要求，则输出 $-1$。
>

> **输出格式:**
> 
> 输出一个整数，表示最少需要的操作次数。如果无法满足导演的要求，则输出 $-1$。

> 
> 对于 $100\%$ 的评测用例，$1 \leq N \leq 10^5$，$1 \leq M \leq 10^9$，$1 \leq P_i \leq N$，$P_1, P_2, \ldots, P_N$ 互不相同。

## 题目大意

初始时，编号 1 到 N 的道具箱按升序排列。目标排列为 $P_1, P_2, \dots, P_N$。每次操作可以交换相邻两个箱子，求将初始序列转换成目标序列的最少次数。要求实际交换次数必须是 $M$ 的整数倍。求满足条件的最小交换次数，若不存在则输出 $-1$。

## 题解

显然在不考虑 *实际交换次数* 是否是 $M$ 的倍数时，最少交换次数就为该序列的 **逆序对** 数量(通过 **树状数组** 快速计算)。

若该序列的逆序对数量为 $M$ 的倍数则直接输出便可。

否则，就需要尝试添加交换次数进行弥补，为了让最终交换后的序列和目标序列一致且交换次数尽可能的少，弥补的方法就为 *选择随机两个相邻的箱子交换两次*。

设指定序列的逆序对数量为 $cnt$，大于等于 $cnt$ 的 $M$ 的最小倍数为 $n \cdot M$。

若 $(n \cdot M - cnt) \% 2 = 0$，那么最终的答案就为 $n \cdot M$。

![](https://img2024.cnblogs.com/blog/2918048/202606/2918048-20260609181158886-1277301127.jpg)

若 $(n \cdot M - cnt) \% 2 \not = 0$，考虑向后增加 $M$ 次交换，尝试是否能找到满足条件的答案。

设 $n \cdot M - cnt = k_{0}$，$k = k_{0} + M$，显然 $k_{0}$ 为奇数(前面哪种情况)，$M$ 有两种情况,

- $M$ 为偶数，则 $K$ 为奇数，无论如何也无法找到满足条件的答案。输出 $-1$。
- $M$ 为奇数，则 $K$ 为偶数，满足条件的最小交换次数就是 $(n + 1) \cdot M$。

**代码:**

```c++
template <typename T>
struct BIT{
    int n; 
    vector<T> tree;
    inline int lowbit(int x){return x & -x;}

    BIT(int sz) : n(sz), tree(sz + 1, T()){}

    template <typename U>
    void build(const vector<U>& arr){
        for(int i = 0; i < n; i ++){
	            update(i + 1, static_cast<T>(arr[i]));
        }
    }

    void update(int idx, T val){
        for(; idx <= n; idx += lowbit(idx)){
            tree[idx] += val;
        }
    }

    T query(int idx){
        T res = T();
        for(; idx > 0; idx -= lowbit(idx)){
            res += tree[idx];
        }
        return res;
    }
    
    T range_query(int lf, int rt){
        if(lf > rt || lf < 1 || rt > n) return 0;
        return query(rt) - query(lf - 1);
    }
};

void solve(void){
    int n, m;
    cin >> n >> m;
    vector<ll> arr(n);
    for(int i = 0; i < n; i ++){
        cin >> arr[i];
    }
    BIT bit = BIT<ll> (n);
    ll cnt = 0;
    for(int i = n - 1; i >= 0; i --){
        int it = arr[i];
        cnt += bit.query(it);
        bit.update(it, 1);
    }
    if(cnt == 0){
        cout << 0 << endl;
        return;
    }
    ll sum = (ll)((cnt + m - 1) / m) * m;
    ll k = sum - cnt;
    if((k & 1) && m % 2 == 0){
        cout << -1 << endl;
        return;
    }
    if(k & 1) k += m;
    cout << k + cnt << endl;
}
```

**时间复杂度:** $O(n \log{n})$

# [P12885 [蓝桥杯 2025 国 Java B] 农场监控](https://www.luogu.com.cn/problem/P12885)

> **题目描述:**
> 
> 一位农民正在规划他的高科技农场，他希望利用无人机和摄像头对农作物进行实时监控。为了实现这一目标，他将农场划分为一个 $2025 \times 2025$ 的网格，其中每个网格单元代表一小块农田。整个网格中共有 $2026 \times 2026$ 个顶点（即网格线相交形成的点），这些顶点可以作为监控设备的安装位置。
> 
> 为了提高监控效率，农民决定选择一个矩形区域进行重点监测。具体来说，他会选择网格中 4 个不同的顶点作为矩形的四个顶点，并且保证矩形的边必须平行于网格的水平或垂直方向。
> 
> 现在，请你帮助这位农民计算，总共有多少种方法，可以选择 4 个点，构成满足上述条件的矩形。两种选法被视为不同的方法当且仅当最后形成的矩形区域不同。
> 
> **输入格式:**
> 
> 无
> 
> 输出格式
> 
> 这是一道结果填空的题，你只需要算出结果后提交即可。本题的结果为一个整数，在提交答案时只填写这个整数，填写多余的内容将无法得分。

## 题目大意

问在一个 $2026 \times 2026$ 的点阵中，选择 $4$ 个不同点组成一个矩形的方案有多少种。

## 题解

换一种方式思考，一个矩形是有由两组相互平行线组成的。

于是，就可以从挑选点转换为挑选线。

对于 $x$ 轴方向上挑选的可能性为 $C_{2026}^{2}$ 种可能，对于 $y$ 轴方向也是相同的 $C_{2026}^{2}$ 种可能。

所以最终答案就为 $\left(C_{2026}^{2}\right)^{2} = 4207934255625$。

**代码:**

```c++
void solve(void){
    cout << "4207934255625" << endl;
}
```

**时间复杂度:** $O(1)$

# [P12886 [蓝桥杯 2025 国 Java B] 分配房子](https://www.luogu.com.cn/problem/P12886)

> **题目描述:**
> 
> 蓝桥小镇有 $20255202$ 栋楼房排成一列，每栋楼有两套房子：一套在一楼，一套在二楼。镇长决定将这些房子分配给本地居民或外来游客居住，并设定了如下规则：
> 
> - 每一栋楼里，必须有一套是本地居民住，另一套是外来游客住。
> - 从本地居民住户中，分别往左、右看同一楼层的邻居。如果某个邻居也住着本地居民，就记录一次（如果某个本地居民的同一楼层的左、右邻居都是本地居民，记录两次）。最后把所有这样的记录加起来，总数是 $5202$。
> 
> 现在，请你计算出满足这两个规则的房子分配方案总数。由于答案可能很大，你只需给出其对 $10^9 + 7$ 取余后的结果即可。
> 
> **输入格式:**
> 
> 无
> 
> **输出格式**
> 
> 这是一道结果填空的题，你只需要算出结果后提交即可。本题的结果为一个整数，在提交答案时只填写这个整数，填写多余的内容将无法得分。

## 题目大意

有 $20255202$ 栋楼排成一列，每栋楼有上下两层。每栋楼必须恰好安排一户本地居民和一名游客（即一层住本地，另一层住游客）。对于同一楼层，若相邻栋楼的该层同为本地居民，则记录 1 次（左右单独计算）。已知所有楼层中这样的记录的总和为 $5202$。求满足条件的分配方案总数（答案对 $10^9+7$ 取模）。

## 题解

可以发现，对于住同一层的两个相邻的本地居民，相互都会贡献一次记录，那么这一组本地居民就会贡献 $2$ 个记录。

已知所有楼层中这样的记录共为 $5202$ 个，那么也就代表了共有 $2601$ 组相邻且在同一楼层的本地游客。

问题就可以转换成，在 $20255202$ 栋楼中挑选 $2601$ 组相邻楼宇的方案数，同时由于其中每一组都可以选择上下两层，所以最终的答案还要乘 $2$。

故答案为 $C_{20255201}^{2601} \times 2 ~\%~ (1e9 + 7) = 728601046$ 。

**代码:**

```c++
const int MOD = 1e9 + 7;

ll fmod(ll x, ll n){
    ll ans = 1;
    while(n){
        if(n & 1){
            ans = ans * x % MOD;
        }
        n >>= 1;
        x = x * x % MOD;
    }
    return ans;
}

void solve(void){
    ll ans = 1;
    ll flag = 1;
    for(int i = 20255201, cnt = 2601; cnt; i --, cnt --){
        ans = ans * i % MOD;
        flag = flag * cnt % MOD;
    }
    ans = ans * fmod(flag, MOD - 2) % MOD;
    cout << ans * 2 % MOD << endl;
}
```

**时间复杂度:** $O(1)$

# [P12887 [蓝桥杯 2025 国 Java B] 答题数量](https://www.luogu.com.cn/problem/P12887)

> **题目描述:**
> 
> 小蓝从一间空荡的房间中醒来，眼前放着一张木桌，桌上摆放着两份密封的答案纸，一份属于他，另一份属于他的朋友。每张纸上都写着一个长度为 $N$ 的字符串，仅包含字符 $\tt T$ 和 $\tt F$ ——这是他们昨晚参加一场判断题考试后的答题记录。
> 
> 考试共有 $N$ 道题目，每题的答案只有两种可能：
> - $\tt T$ 表示 $\text{True}$（正确）
> - $\tt F$ 表示 $\text{False}$（错误）
> 
> 两人在相互隔离、无法交流的情况下各自完成了作答，并提交了自己的答案。
> 
> 今早，小蓝收到了一条神秘信息：
> > “你的朋友恰好答对了 $M$ 道题。”
> 
> 标准答案尚未公布，小蓝无法直接判断自己答对了多少题。然而，基于已知信息，小蓝希望评估出，在所有可能的标准答案中，他自己最多能答对多少题。现在，请你计算小蓝至多能答对的题目数量。
> 
> **输入格式:**
> 
> 第一行包含两个整数 $N$ 和 $M$，分别表示题目数量和朋友答对的题目数量。
> 
> 第二行包含一个长度为 $N$、仅由字符 $\text{T}$ 和 $\text{F}$ 组成的字符串 $S$，表示小蓝的答案。
> 
> 第三行包含一个长度为 $N$、仅由字符 $\text{T}$ 和 $\text{F}$ 组成的字符串 $T$，表示朋友的答案。
> 
> **输出格式:**
> 
> 输出一个整数，表示在所有可能的标准答案中，小蓝最多能答对的题目数量。
> 
> **样例:**
> 
> ```text
> 输入:
> 4 2
> TTFF
> FTTF
> 
> 输出:
> 4
> ```
> 
> **数据规模:**
> 
> 对于 $100\%$ 的评测用例，$2 \leq M \leq N \leq 10^5$。

## 题目大意

有 $N$ 道判断题，已知小蓝的答案字符串 $S$ 和朋友的答案字符串 $T$，且朋友恰好答对了 $M$ 道题。在所有可能的标准答案中，求小蓝最多能答对的题目数量。

## 题解

假设标准答案为 $R$ (长度为 $N$ 的 $T/F$ 串)。

首先，对比下 $S$ 和 $T$ 字符串。

- $S[i] = T[i]$
  该选项小蓝和朋友相同，如果朋友是正确的，则小蓝也正确。
- $S[i] \not = T[i]$ 
  该选项小蓝和朋友不同，如果朋友是正确的，则小蓝是错误的。

设 $S$ 和 $T$ 字符串中相同的有 $A$ 个，不同的有 $B$ 个。

假设在相同的部分中，朋友正确了 $x$ 个，在不同的部分中，朋友正确了 $y = M - x$ 个。

$$
\begin{split}
	\text{小蓝正确的个数} 
	&= \text{相同部分小蓝正确的个数} + \text{不同部分小蓝正确的个数} \\
	&= \text{相同部分朋友正确的个数} + \text{不同部分朋友错误的个数} \\
	&= x + (B - y), \\
	&= x + B - (M - x) \\
	&= 2x + B - M
\end{split}
$$

可以得到，小蓝正确的个数和 $x$ 成正比，所以需要尽可能的让 $x$ 更大。

已知，$0 \le x \le A$ 和 $y = M - x \ge 0$ 即 $x \le M$。

所以, $x$ 最大为 $min(A, M)$。

综上，答案为 $2 \times min(A, M) + B - M$。

**代码:**

```c++
void solve(void){
    int n, m; cin >> n >> m;
    string s, t;
    cin >> s >> t;
    int a = 0;
    int b = 0;
    for(int i = 0; i < n; i ++){
        if(s[i] == t[i]) a ++;
    }
    b = n - a;
    cout << 2 * min(a, m) + b - m << endl;
}
```

**时间复杂度:** $O(n)$
